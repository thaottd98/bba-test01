Lession 2 & 3:
1. Biến (Variables)
- Dùng để lưu trữ dữ liệu
- Khai báo:
<từ khóa> <tên biến> = <giá trị>
    + var (cũ ít dùng)
    + let (có thể thay đổi)
    + const (không thay đổi)
- Quy tắc đặt tên"
    + camelCase: đặt tên biến,hàm
    + kebab-case: đặt tên file và folder
    + PascalCase: đặt tên class
2. Kiểu dữ liệu (data types)
- Primitive:
    + String
    + Number
    + Boolean
    + Undefined
    + Null
    + BigInt
- Complex:
    + Array
    + Object (key-value)
3. Toán tử (Operators)
- Toán học: + - * / %
- So sánh: ==, ===, !=, !== 
-> Note: == so sánh giá trị có ép kiểu
         === so sánh cả giá trị + kiểu (nên dùng)
- Logic: &&, ||, !
- Toán tử 1 ngôi:
    + prefix: ++x,--x tăng/giảm trước, trả về sau
    + prostfix: x++,x-- trả về trước, tăng/giảm sau
4. Câu lệnh điều kiện (Control flow)
- if
- if else
- if else if else
- switch case
if (condition) {
  // code
} else {
  // code
}
-> Dùng để: 
            + xử lý logic testcase
            + Vaildate dữ liệu
5. Vòng lặp (Loops)
- for (i)
- for (of)
- for (each)
- for (in)
- while
- do while
-> Dùng để: 
            + Duyệt list API response
            + Lặp test data
6. Hàm (Functions)
Khai báo:
function <nameFunction>(){
    //code
}
- Giúp tái sử dụng code, thực hiện 1 nhiệm vụ, hoặc một tính toán cụ thể
- Parameter
- return value
